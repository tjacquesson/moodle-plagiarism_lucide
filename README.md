# Lucide for Moodle (plagiarism_lucide)

Detects text generated by artificial intelligence in assignment submissions, with
[Lucide](https://lucide.ai), a detector trained for French.

- Installation guide (French): https://lucide.ai/moodle/
- Download: https://lucide.ai/downloads/plagiarism_lucide-1.0.0.zip
  (SHA-256 `50de3eeec21235970d7291fcb8f882d05dc6685a9fef82c1ef23bc350e94a910`)
- Support: contact@lucide.ai

Teachers switch Lucide on in an assignment. Each online text and each PDF, Word
(.docx), text or Markdown file handed in is analysed in the background. The
teacher sees the verdict next to the work and opens a report with the analysed
text and the passages that read as AI highlighted. Students see a short notice
on the submission page, never the result.

A Lucide outage never prevents a student from handing in: observers only write
local rows, and every call to Lucide runs in a scheduled task.

## Requirements

- Moodle 4.5 LTS to 5.2
- The Moodle cron running every minute
- Outgoing HTTPS from the Moodle server to `api.lucide.ai`
- A Lucide subscription (any plan) and an API key with three rights:
  run analyses, import files, delete analyses

## Installation

1. Download `plagiarism_lucide.zip` and install it from *Site administration →
   Plugins → Install plugins*, or unzip it into `plagiarism/lucide`
   (`public/plagiarism/lucide` from Moodle 5.1).
2. Enable plagiarism plugins: *Site administration → Development → Advanced
   features → Enable plagiarism plugins*.
3. Open *Site administration → Plugins → Plagiarism → Lucide*, tick *Enable
   Lucide*, paste the API key, save, then click *Test the connection*.
4. In an assignment, open *Settings → Lucide — AI-generated text detection* and
   tick *Analyse submissions with Lucide*.

## What is sent, what is kept

- Sent to Lucide: the plain text of online submissions, and submitted files under
  a neutral name (`submission.pdf`). No name, email address, course title or
  file name is sent. A text may still contain personal data written by its author.
- By default, the plugin asks Lucide to erase the text and its result as soon as
  the report is stored in Moodle. Otherwise Lucide keeps them 7 days.
- Moodle keeps the report (analysed text, verdict, highlighted passages) for the
  period chosen by the administrator (1 year by default). Deleting the
  submission, the activity or the user erases it at once, and the Privacy API
  exports and deletes it on request.

## Credits

1 Lucide credit per 100 words, taken from the Lucide account that owns the key.
A text refused as too short or unreadable costs nothing. Handing in the same text
again, or a retry after a network failure, is never charged twice: each source
carries an idempotency key created before the first call.

## Reading a result

The verdict is a clue to examine together with the work and its context. On its
own it is not proof of cheating. The human-likeness score is a decision score of
the model, not a probability that a person cheated nor a share of the text.

## Development

The API endpoint can be changed for development only, in `config.php`:

```php
$CFG->plagiarism_lucide_apiurl = 'https://staging.example/api/v1';
```

Tests: `vendor/bin/phpunit --testsuite plagiarism_lucide_testsuite`.
